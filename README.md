# IKAOPLL-verilator (clean rewrite)

This branch is a clean rewrite of the IKAOPLL Verilator+C driver.

- `rtl/` : IKAOPLL RTL (copied from the original project, unmodified)
- `src/` : C/C++ driver (C-focused API, thin C++ wrapper for Verilator)
- `vgm_data/` : VGM-derived CSV patterns (copied from ikaopll-vgm-testbench)
